# Noto Sans SC

Self-hosted Noto Sans SC variable WOFF2, weights 400–600, distributed under the SIL Open Font License. See [OFL.txt](./OFL.txt).

Source: Google Fonts' [Noto Sans SC](https://fonts.google.com/noto/specimen/Noto+Sans+SC), font build v41, downloaded 2026-10-04. `fonts.css` retains the upstream Unicode ranges and loads only the subsets needed by the current page. All font requests stay on the site's own origin; no runtime Google Fonts connection is required.

The CSS alias `Waterline Sans` avoids ambiguity with fonts installed on the player's device. Font binaries have not been modified. Missing glyphs fall back to the operating system's Chinese sans-serif font.
